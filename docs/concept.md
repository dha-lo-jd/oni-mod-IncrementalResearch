# 研究放置ゲームmod 構想まとめ

Oct 28, 2026 · @かを

## コンセプトと入出力の方針

研究ツリー完了後の研究設備に、放置型クリッカーの構造で継続的な役割を与えるエンドコンテンツ。放置ゲームへの入力は太く、本編への出力は限りなく細くする。

- **狙い**：エンドコンテンツ需要を満たす。研究設備を最後まで回す価値のある施設にする。研究のフレーバーを活かす。リピート性とライフサイクルのある構造を持たせる。
- **入力は太く**：研究の種類ごとの役割分担、現物の納品、大電力の消費、研究者の腕前、上位設備のための環境構築と維持。本編との関わりはここで感じさせる。
- **出力は細く**：放置ゲームの数字は指数的に伸びるため、本編への影響は最小限にとどめる。数字の伸びそのものは放置ゲーム内に閉じる。
- ONIはプレイ中もゲーム内時間が流れ続けるので、拠点づくりの裏で数字が育つ放置ゲームの体験が自然に生まれる。
- 通知は控えめにし、研究画面を開いたときにまとめて確認する形にする（通知欄を埋めてUXを損ねない）。

## 通貨と生産の階層

基本通貨は「知見」。上の段が下の段を生む指数的な生産構造を、研究の言葉で表す。

- **知見**：研究設備が生み出す基本通貨。土台の速度は、研究作業をする複製人間の数と腕前で決まる（クリッカーの「クリック」にあたる）。
- **生産の階層**：仮説が知見を生み、理論が仮説を生み、法則が理論を生む、のように段が上がるほど成長が加速する。
- **研究規模（スケール値。仕様書では「拡張段階」、階層ごとの固有単位名で呼ぶ。docs/spec-knowledge-tier1.md 参照）**：クリッカーの「購入台数」の代わり。知見を払って上げる。バニラ側のコストはなく、放置ゲーム側のコストが指数的に増える。生産量は研究規模に比例する。
- 生産は「放置で伸びる倍率」と「コロニーが供給する研究の土台」の掛け算になる。
- 研究の種類（基礎・上級・軌道・原子力など）を別の段や通貨に結びつけ、一種類だけでは伸びないようにする。

## 上位設備とバニラ側クエスト

上位階層の設備は新しい建物として追加し、その入手を知見ではなくバニラ側の要求（資源、環境、スペース）にする。購入が一瞬の操作ではなく、コロニーの建築と環境づくりになる点が既存クリッカーとの違い。

- バニラ側は各階層1台を建てればよい。これがその階層を使う資格になる。台数の役割は研究規模が担う。
- 環境の条件は稼働中ずっと求められる。冷却が追いつかない、真空が破れる、などで設備が止まると、その階層の研究規模すべての生産が止まる。投資が大きいほど環境維持の重みが増す。
- 上位設備ほど発熱も大きく、冷却設備の規模も問われる。
- 次の階層の解禁は二段構え：放置ゲーム側で下の階層の研究規模が一定に達すると設計図が解禁され、バニラ側で設備を建てて環境を整える。

| 階層の例 | 主な要求 |
| --- | --- |
| 記録保管庫 | 一般的な素材、少しの電力 |
| 計算機室 | 鋼鉄、一定温度以下への冷却の維持 |
| 真空実験室 | 真空の部屋での稼働 |
| 極低温実験装置 | 極低温環境、超冷却剤などの素材 |
| 粒子加速器 | 横に長い設置スペース、放射線粒子の入力 |
| 軌道上研究所 | ロケット内部への設置（Spaced Out!） |

## パラダイムシフトとシンギュラリティ

転生は二層。パラダイムシフトは放置ゲーム強化の主軸で量の変化、シンギュラリティは放置ゲームの最終目標で本編との関連が主軸の質の変化。

### パラダイムシフト

- ひたすら繰り返す前提。
- リセット：知見と研究規模。
- 獲得：パラダイム通貨。以後の生産すべてに倍率をかける。放置ゲーム内でのみ使い、本編向け報酬の購入には使えない。
- 案：シフトのたびに「学派」を選ぶ（実験主義＝下位階層を強化、理論主義＝上位階層を強化など）。

### シンギュラリティ

- 何度も起こせる。放置ゲームの最終目標。
- リセット：パラダイムを含む放置ゲーム側のすべて。
- 獲得：シンギュラリティ通貨。放置ゲームのメタ要素（条件を満たしたら自動でパラダイムシフトなど）、CCで買う拡張、本編向け報酬の購入に使える。
- 拡張は通貨ごとに3種類（知見の拡張、メタ知見の拡張、CCの拡張）。自動購入の扱いは docs/spec-upgrades.md の「拡張の種類と自動購入」を参照。
- 自動化に投資して次を早めるか、本編の報酬に使うか、という「先行投資か回収か」の判断が生まれる。
- 発動条件として、バニラ側にデータバンクの納品を要求し、その量を回ごとに指数的に増やす。序盤は放置ゲーム側が壁、周回を重ねるとバニラ側の生産力が壁になる。

### 共通

- 転生でリセットするのは放置ゲーム側の数字だけ。バニラ側の建物や環境には一切触れない。

## 本編への報酬構造とバランス弁

本編に影響する報酬は、シンギュラリティ通貨での購入と、パラダイムシフトの節目回数からのみ得られる。指数的に増える通貨が本編へ直接流れ出さない構造にする。

- **パラダイムシフトの節目**：初回・10回目・100回目などに本編向けの特別報酬。通貨ではなく回数で決まる。
- **購入数制限つきの報酬**：相対的に実効性が大きいもの（なるべく控えめにする）。上限があるので本編への影響の総量を見積もれる。
- **永続的に購入可能な報酬**：コストを指数的に増やして現実的には有限にし、効果もほぼ影響のないものにする。
- **報酬の例**：複製人間の称号、記念碑や研究の成果を描いた絵画（装飾値はバニラの彫刻程度）、データベースに追加される研究の小話、上限つきのごく小さな恩恵、シンギュラリティ記念の特別な建物。
- **通貨の稼ぎ方の歯止め**：シンギュラリティ通貨の稼ぎが指数的に伸びると、永続報酬の指数的コストに追いつかれる。1回あたりの獲得量を一定または緩やかな伸びにし、データバンク納品という本編側の関門で回数を抑える。

- [ ] データバンクの入手手段はDLCの有無で変わるはず。ベースゲームのみの環境での代替納品物を検討。

## 確定事項(本編向け報酬: 複製人間の強化)

本ドキュメントの他の記述は構想段階だが、この節の内容は決定済み。報酬は「属性ボーナス」と「興味関心の付与」の2種で、どちらもシンギュラリティ通貨で購入する。

### 属性ボーナス

- 対象はコロニー全体。新しい複製人間にも自動で効く。
- 1回の購入で、ランダムに選んだ1属性に +0.1 を加算する(加算方式)。
- 上限は属性ごとに +2.0、全体で +5.0(購入は最大50回)。
- 上限に達した属性は抽選から除外する(当たった場合は再抽選)。
- 購入コストは購入回数に応じて指数的に増える。
- リセットはコロニー全体を一括で行い、ボーナス値と購入履歴を両方消す。リセット費用は固定費。
- セーブ・ロードによる再抽選への対策は行わない。

### 興味関心の付与

- 対象はプレイヤーが任意に選んだ個体。
- 付与する分野はランダム。その個体が既に持っている分野は抽選から除外する。
- 付与は個体ごとに2回まで。全ての興味関心が埋まっている個体には購入不可。
- リセットは個体単位。付与分だけを消し、元から持っている興味関心は保持する。
- リセット費用は固定費で、属性ボーナスのリセット費用とは別の金額にする。

### 実装メモ(Assembly-CSharp の調査結果)

- 属性の最終値は `AttributeInstance.GetTotalValue()` が基礎値に各 `AttributeModifier` を足して求める。上限での丸めはないため、独自の `AttributeModifier` を `AttributeInstance.Add` すれば属性レベルの上限を超えて 0.1 単位で上乗せできる。説明文を付ければ属性ツールチップに内訳が出る。
- 属性レベルの上限(`AttributeLevels.maxAttributeLevel`)は経験値で上がるレベルだけの制限で、上記の modifier には影響しない。
- 複製人間の生成時とロード時に modifier を付け直す処理が必要。
- 興味関心は `MinionResume.SetAptitude(skillGroupId, amount)` で付与できる(`AptitudeBySkillGroup` に書き込む)。経験値倍率とスキル習得条件に効く。士気ボーナスへの影響は未確認。
- 付与前の値を個体ごとに記録しておき、リセット時にその値へ戻す。

# 本編向け報酬の仕様

実装済み(ゲーム内の動作は未検証)。報酬の種類と基本ルールは `docs/concept.md` の「確定事項(本編向け報酬: 複製人間の強化)」で決めたとおり。ここには、価格と操作の形、節目報酬を決めた内容を書く。

数値は `Core/RewardRules.cs`、状態は `Core/RewardState.cs`、複製人間への反映は `Core/RewardEffects.cs`。

## 属性ボーナス

- 1回の購入で、ランダムに選んだ1属性に +0.1 を足す。対象は11属性(運動、力、掘削、建設、機械、学習、料理、植物、芸術、介護、牧畜)。
- 上限は属性ごとに +2.0、全体で +5.0(購入は最大50回)。上限に達した属性は抽選から除く。
- コストは、いま持っている購入回数 n に対して `round(1 + n²/5)` CC の二次曲線。1回目は1 CC、10回目は17 CC、20回目は73 CC、30回目は169 CC、50回目は481 CC。10回分で合計約67 CC、20回分で約514 CC、30回分で約1,740 CC。
- リセットは全体を一括で、5 CC 固定。ボーナス値と購入履歴を両方消す。
- 無料券があれば、CC より先に使う。無料券で買った分は、リセットすると無料券で返る(CCで買った分は返らない)。
- 効果は `AttributeModifier` で付ける。新しい複製人間とロードした複製人間には、`MinionIdentity.OnSpawn` で付け直す。属性のツールチップに「Ⅲ計画の報酬」の内訳が出る。

## 興味関心の付与

- 知見タブの「報酬」の枠で、複製人間を `<` `>` で選んで購入する。
- 付与する分野は、その複製人間がまだ持っていない分野からランダム。1個体につき2回まで。
- コストは、コロニー全体で付与中の件数 k に対して `round(10 + 10k²)` CC の二次曲線。1件目は10 CC、2件目は20 CC、3件目は50 CC、5件目は170 CC、10件目は820 CC。無料券があれば先に使う。
- リセットは個体単位で、5 CC 固定。付与した分だけを外し、付与前の値に戻す。元から持っている興味関心は触らない。無料券で付与した分は、無料券で返る。
- 付与の記録(複製人間のID、分野、付与前の値)はこのMODのセーブに持つ。興味関心そのものは、ゲームが複製人間のセーブに持つ。

## パラダイムシフトの節目報酬

通算のシフト回数(シンギュラリティでリセットしない)が節目に達すると、1回だけ無料券をもらう。通知のダイアログが出る。

| 通算シフト | 属性ボーナスの無料券 | 興味関心の無料券 |
|---|---|---|
| 1回 | 2枚 | 0枚 |
| 10回 | 3枚 | 1枚 |
| 100回 | 5枚 | 2枚 |

合計で、属性ボーナスが最大10回分(+1.0)、興味関心が3回分。数が決まっているので、本編への影響の上限を見積もれる。以前のセーブで始めた場合は、そのときのシフト回数から数え始める。

## UI

- 知見タブの、シンギュラリティの枠の下に「報酬」の枠を足した。CC、無料券、またはボーナスのどれかがあるときに見える。
- 枠の中身: 無料券とCCの残り、属性ボーナスの状況と一覧、購入とリセットのボタン、興味関心の個体選択、付与済みの分野、購入とリセットのボタン。
- デバッグ行に「+3 tickets」(属性3枚、興味関心1枚)を足した。

## ゲーム内で確認すること

- 属性ボーナスを買うと、既存の複製人間の属性が +0.1 上がり、ツールチップに内訳が出る。新しい複製人間にも付く。セーブ・ロードのあとも残る。
- リセットで、全員のボーナスが消える。
- 興味関心を付与すると、その分野の興味関心が複製人間の画面に出る(経験値倍率とスキル習得条件に効く)。リセットで元に戻る。
- 節目の通知が1回だけ出て、無料券が増える。
- 100回目の節目に、現実的な時間で届くか。
